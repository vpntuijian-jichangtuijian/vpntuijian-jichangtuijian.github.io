# 评测方法论与数据审计规范 (Evaluation Methodology)

本项目坚持**客观、透明、可复现**的第三方工程测评标准，拒绝任何虚假宣传与暗箱操作。

## 1. 核心评估维度与权重分配
| 评估维度 | 权重占比 | 核心考察指标 |
| :--- | :--- | :--- |
| **连接稳定性与 SLA** | 30% | 晚高峰（20:00-23:00）丢包率、7×24小时在线率、节点抗封锁能力 |
| **网络吞吐与带宽质量** | 25% | 单线程/多线程下载带宽、4K/8K 视频首帧加载延迟、高峰期测速抖动 |
| **场景适配与解锁能力** | 20% | ChatGPT/Claude 3.5/Sora/Midjourney AI 防封、Netflix/Disney+ 原生落地 |
| **协议现代化与安全性** | 15% | 是否支持 Hysteria 2, VLESS-Reality, Shadowsocks 2022 等防探测协议 |
| **性价比与售后保障** | 10% | 单位流量单价、工单响应时效、退款政策透明度 |

## 2. 自动化巡检机制
项目通过 GitHub Actions 定期执行：
- 节点官网域名与反代链接的可达性探测（响应状态码过滤与重试机制）
- 结构化 YAML 数据的 Schema 格式审查
- 社区反馈与跑路事件的快速熔断
